INSTALLATION
1. Decompresser le ZIP sur votre ordinateur (ne pas envoyer le ZIP tel quel sur GitHub).
2. Ouvrir le depot GitHub qui heberge le site.
3. Remplacer/televerser les FICHIERS DECOMPRESSES a la RACINE du depot,
   en conservant le sous-dossier assets/ et les noms de fichiers.
4. Attendre le deploiement GitHub Pages, puis actualiser le site.

IMPORT GPA (APRES DEPLOIEMENT)

- Choisir le fichier personnel IMPORT_PRIVE_GPA_31_FICHES_2026-11-17.json.
- Controler l'apercu et valider pour ajouter les dossiers manquants.
- NE PAS envoyer le fichier prive GPA sur le depot GitHub.
